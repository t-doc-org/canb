# Se protéger et protéger ses données sur Internet

Vous allez travailler par groupes. Les groupes se trouvent sur Moodle.

Chaque élève consulte tout d'abord individuellement pendant 5-10 minutes le lien
correspondant au thème attribué au groupe et note les éléments importants.

Ensuite, les élèves des différents groupes se mettent ensemble et écrivent à
partir de leurs notes une synthèse des thèmes qui leur ont été attribués (à mettre dans le document partagé dont le lien se trouve sur Moodle - soyez attentif au français ainsi qu'à la
présentation) :

- Groupe 1 : [Pourquoi et comment bien gérer ses mots de passe ?](https://www.cybermalveillance.gouv.fr/tous-nos-contenus/bonnes-pratiques/mots-de-passe)
- Groupe 2 : [Les bonnes pratiques pour naviguer sur Internet](https://www.cybermalveillance.gouv.fr/tous-nos-contenus/actualites/les-bonnes-pratiques-pour-naviguer-sur-internet)
- Groupe 3 : [La sécurité sur les réseaux sociaux](https://www.cybermalveillance.gouv.fr/tous-nos-contenus/bonnes-pratiques/reseaux-sociaux)
- Groupe 4 : [Protéger ses appareils mobiles](https://www.cybermalveillance.gouv.fr/tous-nos-contenus/bonnes-pratiques/appareils-mobiles)
- Groupe 5 : [Pourquoi et comment bien gérer ses mises à jour ?](https://www.cybermalveillance.gouv.fr/tous-nos-contenus/bonnes-pratiques/mises-a-jour)
- Groupe 6 : [Les antivirus](https://www.cybermalveillance.gouv.fr/tous-nos-contenus/bonnes-pratiques/antivirus)
- Groupe 7 : [Pourquoi et comment bien gérer ses sauvegardes ?](https://www.cybermalveillance.gouv.fr/tous-nos-contenus/bonnes-pratiques/sauvegardes)
