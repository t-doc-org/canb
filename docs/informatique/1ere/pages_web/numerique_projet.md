# Projet Numérique et société

## Objectifs

Le but de ce projet est de mieux comprendre les enjeux sociaux, éthiques, juridiques, économiques et environnementaux liés au numérique.

Par groupe, vous allez faire une recherche sur un des thèmes de la [liste des thèmes](numerique_themes), puis présenter le résultat de cette recherche :

- dans une **page web** (HTML et CSS) ;
- dans un **document Word**.

## Déroulement du projet

### 1. Trouver des sources

- Les sources doivent être **variées** : pas seulement des sites web, mais aussi des livres, des magazines, des articles de journaux, etc.
- Ressources en ligne de la bibliothèque : [ressources en ligne](https://new.cscfr.ch/index.php/fr/services/bibliotheque/ressources-en-ligne)
- **Créer un document Word partagé** avec l'enseignant (brice.canvel@edufr.ch). Le titre du document doit contenir votre classe et le numéro du groupe (par exemple 1F3_Groupe_4).
- Pour chaque source, noter dans ce document :
  - la source ;
  - la ou les information(s) pertinente(s) ;
  - une photo (pour un document papier) ou une copie d'écran (pour un document en ligne).

Voir l'[exemple de document de sources][exemple-sources].

### 2. Écrire et organiser le texte

- Réfléchir à l'organisation du texte : différentes parties, titres, sous-titres.
- Pour chaque partie, écrire le texte en indiquant la source (d'où vient l'information) :
  - document papier : titre et numéro de page ;
  - site web : lien vers le site et date de consultation.
- Pour citer les sources, voir le [guide du travail de maturité](https://new.cscfr.ch/images/stories/media/tm/TM_Guide_2025_26_F.pdf) (annexes 2 et 3).

### 3. Créer la page web

Présenter le texte dans une page web. Voir l'[exemple de page web][exemple-page] et les critères du barème ci-dessous.

### 4. Créer le document Word

Présenter le texte dans un document Word mis en forme. Voir les critères du barème ci-dessous.

## Rendu du projet

Délai :
- Classe : *date à compléter*

## Barème

Chaque critère est évalué de 0 à 4 points. Ces points sont ensuite multipliés par la pondération du critère.

| Points | Signification |
|:------:|---------------|
| **0** | Le critère n'est pas rempli (élément absent) |
| **1** | Le critère est rempli de manière insuffisante (nombreuses erreurs ou manques importants) |
| **2** | Le critère est partiellement rempli (plusieurs erreurs ou manques) |
| **3** | Le critère est bien rempli (quelques petites erreurs ou manques) |
| **4** | Le critère est entièrement rempli |

Chacune des trois parties donne une note : **note = points obtenus × 5 / total des points possibles + 1**

### Contenu

| Critère | Points | Pondération |
|---------|:------:|:-----------:|
| Le thème est divisé en différentes sections pertinentes | 0 – 4 | **× 0,5** |
| Le contenu est scientifiquement exact | 0 – 4 | **× 1** |
| Le thème est traité de manière approfondie | 0 – 4 | **× 1** |
| Les sources sont indiquées pour chaque partie du contenu | 0 – 4 | **× 1** |
| La langue est soignée | 0 – 4 | **× 0,5** |

**Total : 16 points possibles** (somme des pondérations : 4 × 4 points)

### Page web (HTML et CSS)

| Critère | Points | Pondération |
|---------|:------:|:-----------:|
| Une table des matières au début de la page contient des liens cliquables vers les différentes sections ([liens dans la même page][liens-page] - voir « Et pour les liens dans la même page ? ») | 0 – 4 | **× 0,5** |
| Les niveaux de titres sont utilisés de manière pertinente (```h1``` : titre de la page, ```h2``` : chapitres, ```h3``` : sous-chapitres, etc.) | 0 – 4 | **× 0,25** |
| La page contient plusieurs images pertinentes (qui aident à la compréhension), avec une description dans l'attribut ```alt``` ([voir l'exemple 5][images]) | 0 – 4 | **× 0,5** |
| La page contient au moins une vidéo en lien avec le thème, insérée directement dans la page ([explications][video]) | 0 – 4 | **× 0,5** |
| La page contient au moins un tableau dont les espacements, la taille des colonnes et la bordure sont modifiés ([explications](https://www.w3schools.com/Css/css_table.asp)) | 0 – 4 | **× 0,5** |
| Les couleurs et les polices de caractères sont personnalisées | 0 – 4 | **× 0,5** |
| Les balises ```meta``` ```author``` et ```description``` sont utilisées dans la partie ```head``` ([explications](https://www.alsacreations.com/article/lire/628-balises-meta.html)) | 0 – 4 | **× 0,5** |
| La présentation générale de la page est lisible et agréable à lire | 0 – 4 | **× 0,75** |
| La page contient une bibliographie (avec des liens cliquables pour les sites visités) | 0 – 4 | **× 0,5** |

**Total : 18 points possibles** (somme des pondérations : 4,5 × 4 points)

### Document Word

| Critère | Points | Pondération |
|---------|:------:|:-----------:|
| Les styles de titres sont utilisés pour les titres (Titre, Titre 1, Titre 2, etc.) | 0 – 4 | **× 1** |
| Les titres sont numérotés automatiquement | 0 – 4 | **× 1** |
| Les paragraphes sont justifiés (alignés à gauche et à droite) en modifiant le style « Normal » | 0 – 4 | **× 0,5** |
| Une table des matières automatique est insérée au-dessous du titre principal | 0 – 4 | **× 1** |
| Les pages sont numérotées automatiquement | 0 – 4 | **× 0,5** |
| Une bibliographie est présente à la fin du document | 0 – 4 | **× 1** |
| Les sources sont référencées correctement à l'intérieur du document | 0 – 4 | **× 2** |

**Total : 28 points possibles** (somme des pondérations : 7 × 4 points)
